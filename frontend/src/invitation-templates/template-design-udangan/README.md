# Kumpulan desain template undangan

Folder ini mengelompokkan desain berdasarkan kategori undangan. Setiap desain yang siap dipakai didaftarkan di `../registry.ts` dan memiliki `Template.astro`, `theme.css`, serta `config.ts`.

Kategori: `pernikahan`, `khitanan`, `aqiqah`, `peresmian`, `launching`, `ulang-tahun`, `wisuda`, `seminar`, dan `lainnya`.

Desain pertama: `pernikahan/batak-senja`. Asetnya berada di `frontend/public/template-design-udangan/pernikahan/batak-senja/`.
